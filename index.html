Pseudocode

The highlighted line matches the current action.

  1. mark start visited; enqueue(start)
  2. while queue is not empty:
  3.   u ← dequeue()
  4.   for each neighbour v of u:
  5.     if v is not visited:
  6.       mark v visited; enqueue(v)
  7. stop when queue is empty
Why BFS? In an unweighted graph, the first time BFS reaches a vertex, it has found a path with the fewest edges. Time: O(V + E).

Assumption: this demo treats edges as undirected. If the graph is disconnected, BFS visits only the vertices reachable from the selected start.
